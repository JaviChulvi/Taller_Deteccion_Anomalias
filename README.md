# Taller de detección de anomalías

Repositorio compartido del taller. Cada participante mantiene su código, notebooks y resultados en una carpeta con su nombre.

## Materiales comunes

- [Enunciado](taller_anomalías.pdf).
- [Notebook original del taller](taller_detección_anomalías.ipynb).
- Datos originales: `credit_card_construction.csv.zip` y `credit_card_production.csv.zip`.

Estos materiales permanecen en la raíz para que todas las aportaciones puedan utilizarlos sin duplicarlos.

## Aportaciones

- [Javi](javi/README.md): diagnóstico, comparativa de modelos, evidencia y entrega de scores.

Para añadir tu trabajo, crea una carpeta con tu nombre y guarda allí tus notebooks, código, dependencias y resultados. Lee los datos compartidos desde la raíz y añade el enlace a tu README en esta lista.
