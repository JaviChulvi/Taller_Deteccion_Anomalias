Protocolo para nuestros datos

  1. Construcción: 170.884 filas, 21 predictores y 295 fraudes (0,173 %). Producción: 113.923 filas sin etiquetas. No hay fecha, identificador de cliente, imagen ni texto.
  2. Comparar los modelos sobre las mismas particiones estratificadas y agrupadas por igualdad de los 21 predictores. La igualdad de patrones no demuestra identidad de transacción; el agrupamiento mide generalización a patrones no repetidos entre particiones.
  3. Medir AP con average_precision_score sobre scores continuos, alto=mayor sospecha. Comparar dispersión entre folds y tiempo. No sustituir AP por el AUROC de los gráficos de ADBench.
  4. Ajustar escalado y transformaciones solo dentro de entrenamiento. Para aprender normalidad, filtrar Class=0 únicamente en train y declarar que esta selección usa etiquetas. Un experimento totalmente no supervisado debe entrenar sin ese filtrado.
  5. La parada temprana y la búsqueda de parámetros usan particiones internas. Los resultados usados para seleccionar modelos no son una evaluación final independiente. El conjunto de construcción ya ha sido explorado.
  6. Conservar prevalencia real en validación. No eliminar automáticamente valores extremos: rareza y fraude no son equivalentes.
  7. Después de seleccionar el procedimiento, producir un score por fila de producción, manteniendo orden y cantidad. No hace falta fijar un umbral binario para la entrega.

Qué conviene corregir al inspirarnos en las prácticas

  • LOF: AD_Data_clase convierte etiquetas con (y_pred+1)/2; eso asigna 1 a normales cuando el objetivo usa 1 para anomalía. Las demostraciones fit_predict no son todavía un predictor de operaciones nuevas.
  • Dirección del score: GMM devuelve log-densidad; para riesgo debe invertirse. Isolation Forest en la práctica sí invierte score_samples. Las etiquetas de DBSCAN no forman un score continuo comparable.
  • Escala: no trasladar la matriz completa de distancias N×N. Con 170.884 filas necesita aproximadamente 217,6 GiB solo para float64. Usar búsqueda de vecinos con memoria acotada si se incorpora ese enfoque.
  • Autoencoders: sustituir MNIST y salidas sigmoides por 21 variables escaladas y salida lineal. Hay diferencias y errores reales entre versiones base y clase; la revisión por archivo los detalla.
  • Dependencias: los notebooks instalan versiones distintas de PyOD y ADBench; las salidas incluso registran conflictos de paquetes. El taller ya dispone de CSV y no necesita copiar esas instalaciones.
  • ECOD: la implementación oficial consultada concatena train y el lote consultado para recalcular ECDF. Su puntuación depende del lote; declarar esa evaluación como transductiva y verificar versión, o estudiar una variante explícita de ECDF congelada.
  • Material anterior: la práctica antigua de PCA/AE sobre ECG invierte la clase normal y mezcla x_norm de entrenamiento con x de inferencia. El NB4 de Keras tiene un protocolo más claro; el NB4 de PyTorch contiene ejercicios pendientes.

Verificación actual de APIs: código oficial de ECOD y detección de anomalías y novelty en scikit-learn.

      def conv_block(inputs, filters, pool = True): ''' Define a convolutional block of the encoder. Arguments: - inputs (tf tensor): Input tensor - filters (int): Number of filters - pool (bool): Do the MaxPooling or not -- True Returns: - x (tf tensor): Output tensor before the MaxPooling - p (tf tensor): Output tensor after the MaxPooling ''' x = tf.keras.layers.Conv2D(filters, 3, padding = "same")(inputs) x = tf.keras.layers.BatchNormalization()(x) x = tf.keras.layers.Activation("relu")(x) x = tf.keras.layers.Dropout(0.2)(x) x = tf.keras.layers.Conv2D(filters, 3, padding = "same")(x) x = tf.keras.layers.BatchNormalization()(x) x = tf.keras.layers.Activation("relu")(x) x = tf.keras.layers.Dropout(0.2)(x) if pool == True: p = tf.keras.layers.MaxPool2D((2, 2))(x) return x, p else: return x def build_unet(shape, num_classes): ''' Build an UNET form model with GDN. Arguments: - shape ((int, int, int)): Shape of the input tensor - num_classes (int): Number of classes Returns: - model (tf model): Model built ''' inputs = tf.keras.Input(shape) # Encoder x1, p1 = conv_block(inputs, 16, pool = True) x2, p2 = conv_block(p1, 32, pool = True) x3, p3 = conv_block(p2, 64, pool = True) x4, p4 = conv_block(p3, 128, pool = True) b1 = conv_block(p4, 256, pool = False) # Decoder u1 = tf.keras.layers.Conv2DTranspose(256, kernel_size = (3, 3), strides = (2, 2), padding = 'same')(b1) c1 = tf.keras.layers.Concatenate()([u1, x4]) x5 = conv_block(c1, 128, pool = False) u2 = tf.keras.layers.Conv2DTranspose(128, kernel_size = (3, 3), strides = (2, 2), padding = 'same')(x5) c2 = tf.keras.layers.Concatenate()([u2, x3]) x6 = conv_block(c2, 64, pool = False) u3 = tf.keras.layers.Conv2DTranspose(64, kernel_size = (3, 3), strides = (2, 2), padding = 'same')(x6) c3 = tf.keras.layers.Concatenate()([u3, x2]) x7 = conv_block(c3, 32, pool = False) u4 = tf.keras.layers.Conv2DTranspose(32, kernel_size = (3, 3), strides = (2, 2), padding = 'same')(x7) c4 = tf.keras.layers.Concatenate()([u4, x1]) x8 = conv_block(c4, 16, pool = False) # Output output = tf.keras.layers.Conv2D(num_classes, 1, padding = 'same', activation = 'relu')(x8) # Para calsificación #output = tf.keras.layers.Conv2D(num_classes, 1, padding = 'same', activation = 'softmax')(x8) return tf.keras.Model(inputs, output)
